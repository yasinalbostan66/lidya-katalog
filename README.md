# 🏢 LİDYA GRUP | Resmi Dijital Ürün Kataloğu & A4 Dikey Broşür Portalı

Lidya Grup Bilişim Sistemleri A.Ş. distribütörlüğündeki tüm endüstriyel dijital baskı, geniş format, ambalaj ve sonlandırma çözümlerini içeren interaktif web portalı ve baskıya hazır A4 dikey broşür koleksiyonu.

---

## 🌟 Canlı Web Portalı (GitHub Pages)

Bu proje GitHub Pages üzerinde doğrudan çalışacak şekilde tasarlanmıştır.

- **Ana Web Portalı:** `index.html` (Dinamik marka filtreleme, ürün kartları ve hızlı broşür erişimi)
- **Genel Ürün Kataloğu (60 Ürün):** `GENEL_URUN_KATALOGU.html` (Tam 60 A4 sayfa)
- **Marka Özel A4 Broşürleri:**
  - 📄 `01_Xerox_Brosuru.html` (Xerox Dijital Üretim Sistemleri)
  - 📄 `02_EFI_Brosuru.html` (EFI Geniş Format & Nozomi Ambalaj)
  - 📄 `03_Keundo_Brosuru.html` (Keundo UV & Eco-Solvent Sistemleri)
  - 📄 `04_Flora_Brosuru.html` (Flora Bobin Inkjet & Geniş Format UV)
  - 📄 `05_Duplo_Brosuru.html` (Duplo Lak, Yaldız, Kesim & Sonlandırma)
  - 📄 `06_Epson_Brosuru.html` (Epson SureColor Profesyonel Serisi)
  - 📄 `07_Sutec_Brosuru.html` (Sutec Dijital DTF & UV Sistemleri)
  - 📄 `08_JWEI_Brosuru.html` (JWEI Endüstriyel Dijital Kesim Masaları)

## 🚀 GitHub Pages Kurulumu (Adım Adım)

1. Deponuzun **Settings** (Ayarlar) sekmesine gidin.
2. Sol menüden **Pages** seçeneğine tıklayın.
3. **Build and deployment > Branch** kısmından `main` dalını ve `/ (root)` dizinini seçip **Save** butonuna basın.
4. Birkaç saniye içinde siteniz `https://<kullanici-adiniz>.github.io/<depo-adiniz>/` adresinde yayına alınacaktır.
